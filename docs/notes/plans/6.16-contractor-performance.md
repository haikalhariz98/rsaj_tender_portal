## 4. Actions (`src/app/projects/[id]/performance/actions.ts`; config in `src/app/configuration/performance/actions.ts`)

Lock order (6.12 `withLockedContract`, source-scanned): Requisition → Exercise → Award → Contract → Certificate → `PerformanceReport`
→ Supplier last. Policy, form, baseline, LAD lines and S.O. assignments re-read inside the transaction; the pure check re-run on
locked rows; every write audited before/after in the same transaction; Persons "recorded on behalf of, not signed".

1. `openPerformanceReport(contractId, stage)`: `stageFaults`, `categoryFor`, classification set; opens the 6.14 certificate
   (kind PERFORMANCE_REPORT, no DAL route: straight to SIGNING-ready DRAFT), pins the issued form version and its snapshot, copies
   `supplierId` from the award (null allowed in DRAFT).
2. `saveScores` (DRAFT only): writes `PerformanceScore`, recomputes `scoreTotal` / `gradeLabel` / LAD block from the lib.
3. `recordAssessorSignature`, `recordVerifierSignature`: 6.14 `recordSignature` after `performanceSignFaults`; the first signature
   freezes scores (template pin, 6.14 OD-2). The verifier's block is `datesCertificate`. Supplier unlinked → refused at the first
   signature with SUPPLIER_NOT_LINKED, naming "link the award in the supplier register".
4. `fileWithContractProcurement`: 6.14 `despatchCopy` on the mandatory C&P recipient; sets `filedAt`; the register sees it.
5. `supersedePerformanceReport(reason)`: new version opened, old one marked superseded in the same transaction; evaluations linked
   to the old one keep their snapshot, labelled "report since superseded".
6. **6.8 hook (own flagged commit, new tests only):** `linkCpr(bidderId, reportId | external | notScored, reason)` in the evaluation
   actions, lock order requisition → exercise → window → Evaluation → bidder, then the `PerformanceReport` row `FOR SHARE` (no
   contract chain is locked, so no cycle with action 5, which locks contract → report). Writes `cprReportId`, `cprSource`,
   `cprSnapshot`, `cprPercent`. 6.8's `recordInputs` stops accepting a typed CPR for REGISTER; existing entered rows read
   "Entered before the register (from the attached report)". The same commit makes 6.8 show the CPR at the report's stored
   precision and band the unrounded figure (OD-2), an exception to E-5's `scoreDecimals` for this input only, flagged.
7. **6.13 B hook (own flagged commit):** `closeContract` calls `performanceClosureFault`.
8. Configuration: categories, forms (draft, issue via `formFaults`, retire with reason), criteria, groups, bands, rules, policy.
