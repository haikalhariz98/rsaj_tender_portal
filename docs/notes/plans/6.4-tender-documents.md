## 2. Data model (additive, nullable or defaulted, `organisationId` on every new model)

### 2.1 Configuration
- `enum PackKind { TENDER QUOTATION NONE }`. `SourcingMethod.documentPackKind PackKind?`. Null blocks the move into preparation (`DOCUMENTS_RULE_NOT_SET`, naming Configuration › Sourcing methods). NONE means no pack (direct, emergency).
- `enum PartRole { INVITATION INSTRUCTIONS FORM_OF_TENDER CONDITIONS APPENDIX LOA_SPECIMEN BOND_FORMS SPECIFICATION BILL_OF_QUANTITIES SUMMARY_AND_RATES REGISTRATION_BACKGROUND DECLARATION DRAWINGS OTHER }`. This is closed product vocabulary, so rules can recognise a part (BD-DS-4 precedent).
- `enum PartContent { STANDARD BESPOKE MIXED }` and `enum PartSource { TEMPLATE BQ_UNPRICED APPENDIX UPLOAD }`.
- `TenderDocumentPart` (org, code, packKind, `contractBasisCode String?` (null: any basis), printedNumber, sortOrder, labelEn/Ms, role, content, source, `mandatory Boolean?`, `inTableDocument Boolean?`, ownerOrgUnitCode?, templateCode?, governingSource, provenance, retiredOn), `@@unique([org, code])`. Ships empty.
- `TenderDocumentPolicy` (org @unique, nullable): `restrictionStampTextEn/Ms`, `assuranceRequired Boolean?`, `ladDailyPct Decimal(9,6)?` + provenance (§8.6), `firstCertificateFloor Decimal?` / `firstCertificatePct Decimal?` + provenance (§8.3), `insuranceExtraMonths Int?` / `insuranceExtraDays Int?` (+ a D&B pair) + provenance (§8.10), `regulatorPermitTaxonomyCode`, notes.
- Inc 2: `ClauseText` (org, code, titleEn/Ms, bodyEn/Ms, bodyVersion, `mandatoryInAgreements Boolean?`, governingSource, provenance, retiredOn). Templates cite it as `{{clause:code}}`.
- New AuthorityRule **domain string** `tendering_approval`. No schema change. Rows are the customer's.
