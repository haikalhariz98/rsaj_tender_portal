## 0. What exists, and what the earlier modules will have built

- **D1 governs everything here.** SK003 has no marks, weights, pass marks or formula; the 60/40 tender model and the five-phase
  quotation model are practice (TA 109, LAPORAN PENILAIAN SEBUTHARGA). So **every weight, pass mark, factor and band is a configuration
  row, shipped empty** (rule 1). The code knows only *kinds* of computation (a weighted sum, a minimum-capital ratio, a variance); the
  numbers are the customer's. TA 109 and the quotation template live in a **test-only fixture** (`evaluation/ta109-fixture.ts`), never
  seeded; RSAJ seeds them at go-live as OBSERVED, pending D1.
- **Arithmetic.** `src/lib/money.ts` has sen as bigint and `compareAmounts`; `percentOfSen` takes a JS number and is **not** used
  here. Scores, weights and percentages get a fixed-point helper (bigint, 4 decimal places, half-up), parsed from decimal strings.
- **People.** No sign-in; `Person.orgUnitCode?` arrives with 6.7 (FR-CTE-011). The requisition's `requestingUnitCode` is the
  implementing department.
- **Committees and routes.** EXERCISE matters with typed `exerciseId` (6.11), `exerciseCitationFault` for appointment steps,
  `NotApprovedOutcome` (LOOP / TERMINAL, `returnsToStage` free text, none shipped). Prototype route domain "Negotiation" exists in the
  sample matrix; the engine has no `negotiation` domain yet.
- **Award (6.11)** keys `awardeeName`, `awardeeRegistrationNo`, `awardedValue`, `completionPeriod`; `issueFaults` and `submitFaults`
  read the exercise status; 6.6 adds `awardValidityFault`; 6.7 replaces the gate (X-9).
- **Templates.** `DocumentTemplate` + `renderTemplate` (moved to `src/lib/templates/merge.ts` by 6.4), frozen at issue (ADR 0008).
- **Prototype** (`sr.ev.*`): model picker "Qualitative assessment" / "Weighted score", weights and pass marks with "Defaults are 60 / 40
  with 70% and 60%" and "Restore defaults", tabs Screening / Scoring / Side by side / Price, arithmetic correction, price band,
  recommendation with "not the top ranked bidder: state the reason", report "Build / Issue for decision". **Not reproduced:** defaults
  and "Restore defaults" (rule 1), "scores commit as you type" re-ranking a live model (FR-EVL-006 freezes it), the quotation rule
  applied to a tender (FR-EVL-007), the hard-coded estimate. Comparators record each in `DECIDED_FIELDS`.
