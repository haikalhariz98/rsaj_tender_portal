## 0. What the code says today (findings)

- **Award hangs on 6.3's `SourcingExercise`** (ADR 0006), not yet built: this migration lands **after `requisition_intake` and 6.3's
  migration**. The exercise carries the snapshots the award needs: `requisitionId`, `sourcingMethodCode`, `contractTypeCode`,
  `regime`, `appointmentRuleKey`, `termsBandKey`/`termsState`, `boundaryOperator`/`onBoundary`/`boundaryRuled`. **The award reads them;
  it never re-derives or copies them.** Exercise status in Phase 1 is DRAFT, DOCUMENTS_IN_PREPARATION or CANCELLED; 6.5 adds AWARDED.
- 6.3 leaves `CommitteeDecision.exerciseId` to "whichever module first tables an exercise", and that is this one (the appointment matter).
  6.3 locks the contract type at `classificationLockedAt`, "set by 6.11": set when the award is submitted for appointment approval.
- There is no Vendor model (Phase 3). 6.1 defines no appointment instance; 6.3 adds `ApprovalInstance.exerciseId`.
- `decisionRecord()` exists (`src/lib/committee/record.ts`): null while PENDING, otherwise the frozen outcome, date and votes. It carries
  the committee **name**, not its code, so the gate checks the committee through the linked `Meeting.committee.code`.
- `DocumentTemplate` has form code, revision date and bilingual flag, **but no body**. Nothing generates or stores a document.
- `SourcingMethod.awardInstrument` is free text; nothing reads it. `NumberingSeries` key `contract` exists in demo only.
- `NotificationRule` (eventKey + `reminderOffsetDays`) exists and sends nothing. There is no delivery infrastructure.
- The prototype's award tab (`sr.aw.*`) has one unconditional "Issue the award" button, "{n}% of the accepted value" for the bond (a
  hard-coded basis, contrary to D4), "Contractor all risks and workmen's compensation", distribution and unsuccessful suppliers.

## 4. Generating the instrument without a document engine (ADR 0008)

- **Template body is configuration.** Additive `DocumentTemplate.bodyMs Text?`, `bodyEn Text?`, `primaryLanguage` (ms/en) and
  `bodyVersion Int @default(0)`, bumped on every audited body edit. The body is plain text with whitelisted `{{field}}` merge fields.
  No markup engine, no HTML stored, rendered through React text nodes (no `dangerouslySetInnerHTML`). **Ships empty.** An unset body
  shows "Template text not configured", and issue refuses. No customer's letter wording ships (AGENTS.md).
- **Preview vs issue.** Before issue, `/awards/[id]/print/[kind]` renders live with a "PREVIEW, not issued" band. On issue, each
  document is frozen into `AwardDocument` (fields, rendered text, template version, `frozenAt`), and the print route renders **only the
  snapshot**, never live configuration. The same principle as `decisionRecord`.
- **Every printed page** carries the reference, version, form code and revision, and `frozenAt` (not now(), so NFR-GEN-003 and 004
  agree). It also carries a watermark: **"Draft, not signed. Not a controlled copy."** Print CSS (`@page`) only. The officer prints, has
  it signed on paper, and records the return (§2 `AwardReturn`).
- **Bilingual (NFR-LNG-002):** the language is the template's `primaryLanguage`. A second-language copy is offered when the other body is set.
- **Indent:** the Inden Kerja is an ERP document (Appendix C "R"). We record its number and receipt and generate only the covering memo
  and the Pemberitahuan Perlantikan.
- **Deferred:**
  - form fidelity, "n of m" paging, tick-box and strike-out conventions, and bilingual label pairs (NFR-GEN-001/002, LNG-003) → the Phase 4e certificate engine;
  - a PDF file, e-signature, and attaching scanned returns → document storage;
  - sending copies → delivery infrastructure.
- **Façade (INT-04/05):** `src/lib/integration/award-commitment.ts` defines `interface CommitmentGateway { requestCommitment(a:
  AwardOutbound): Promise<void>; recordNumber(awardId, no, on): Promise<void> }`. The only adapter is `manualCommitment`, where the
  officer types the IN/PO number. The `/awards` view "Issued, no commitment number" is the INT-05 reconciliation list.

## 5. FR-CTE-014: routing-sheet committee block (read only)

- `committeeBlock(rec, ceoStep)` returns `{committee, meetingDate, meetingReference, outcome, decisionDate} | "NOT_DECIDED"`, plus the
  CEO block `{receivedOn | "not recorded", approverName, decidedOn}` from the appointment instance's A step.
- **No column stores these fields and no form accepts them.** They are rendered on the award's Approval tab, and offered as merge fields
  (`{{committee.meetingDate}}` …) for the covering memo, where they freeze with the document on issue.
- The source is `decisionRecord()` for the decision linked by `ApprovalStep.committeeDecisionId`, and nothing else. A MINUTED meeting
  is already frozen by 6.10.
