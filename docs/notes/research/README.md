# Research

One file per question: `0001-short-topic.md`.

For questions this codebase cannot answer — how established products handle a problem,
what a regulation actually requires, whether a library is worth adopting, what an external
API can really do.

Each file states:

- **The question**, and what a good answer would let us decide
- **The short answer**, in the first paragraph
- **The recommendation**, with the strongest argument against it
- **The evidence**, cited with links and publication dates
- **What could not be established**, and where it would be found
- **What would change the answer**

Dates matter more than they look. Prices, API capabilities, regulations and library health
all rot, and a citation without a date cannot be re-checked later.
